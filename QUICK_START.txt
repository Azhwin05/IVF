================================================================================
  TROUBLESHOOTING
================================================================================

Issue: npm install fails
Solution: Delete node_modules, clear npm cache, reinstall

Issue: Port 3000 already in use
Solution: Change port: npm run dev -- -p 3001

Issue: Browser doesn't load
Solution: Check terminal for error messages. Ensure Node.js 18+

Issue: Screen shows blank
Solution: Hard refresh browser (Ctrl+Shift+R or Cmd+Shift+R)

Issue: Slow performance
Solution: This is a dev server. Production will be much faster.
