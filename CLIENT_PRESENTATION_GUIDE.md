## 🚀 Quick Start (30 seconds to live demo)

### Prerequisites
- Node.js 18 or higher installed
- npm or yarn package manager

### Launch Instructions

```bash
# 1. Navigate to the prototype folder
cd dr-archana-ivf-prototype

# 2. Install dependencies (first time only)
npm install

# 3. Start the development server
npm run dev

# 4. Open in your browser
# → http://localhost:3000

# Done! The prototype loads immediately.
```

**The entire startup takes about 60 seconds.**

## 💡 Key Talking Points

### Why This Design?

**Emerald + Stone Aesthetic**
- Emerald: Hope, growth, life (appropriate for fertility care)
- Stone: Stability, trust, professionalism
- Together: Premium clinical confidence

**Not Like Other Hospital Software**
- No cluttered dashboards
- No generic blue-and-white admin panels
- No dense spreadsheet layouts
- This is designed specifically for IVF workflows

### The Real Problem It Solves

**Current Situation (Without This System):**
- Patient data scattered across multiple systems
- Couples not truly connected in the system
- Embryology data separate from clinical records
- Monitoring results don't link to treatment decisions
- Billing disconnected from clinical care
- Each team member seeing different "versions of truth"

**With This System:**
- One unified source of truth
- Complete patient journey visible
- Every data point connected to clinical context
- Automatic compliance and audit trails
- Every role sees exactly what they need

### The Business Impact

1. **Efficiency**: Doctors spend less time searching for data
2. **Safety**: Complete records mean fewer clinical errors
3. **Patient Satisfaction**: Couples see their journey tracked and managed
4. **Scalability**: Same interface handles 5 couples or 500 couples
5. **Revenue**: Integrated billing means better collection and fewer late payments
6. **Compliance**: Automatic audit trails for regulatory requirements

## ❓ Anticipated Questions

### "Can this handle our current patient volume?"
> "Absolutely. This prototype is built on React and Next.js, which scales to millions of concurrent users. During development, we'll load-test with your actual volume and optimize accordingly. Enterprise systems handle 5x our projected volume without issue."

### "How is patient data protected?"
> "The prototype doesn't connect to a real database by design—it's a UI demonstration. The production system will include: HIPAA-compliant encryption, role-based access control with audit logging, secure session management, and automated compliance reporting. We'll work with your IT team to meet all regulatory requirements."

### "What about integration with our existing systems?"
> "We can build API connectors for any existing system—billing software, lab equipment, email platforms, SMS gateways. This prototype shows the UI independently, but integrations are straightforward. We'll map existing systems during the requirements phase."

### "Can we customize the workflows?"
> "Yes. This prototype shows our recommended workflows based on IVF best practices. During development, we'll work with your team to customize each workflow. If your process is different, we adapt. You own the workflows."

### "How much would this actually cost?"
> "We'll prepare a detailed proposal after understanding your complete requirements. Ballpark for a production system: ₹25-40L including database, API, security hardening, compliance testing, deployment, and 6 months of support. This is significantly less than enterprise HMIS solutions and built specifically for IVF."

### "How long to build?"

> - Phase 1 (Weeks 1-8): Core workflows (Dashboard, Patient Management, Monitoring, Embryology)
